RomRaider2 ECU Studio 1.1.0 RC3
================================

RC3 is still in development. The public download remains RC2 until the new
Windows and Linux packages pass their release checks.

Changes since RC2
-----------------

Logger

- Rebuilt the main Logger layout around Data, Graph, Dashboard, MAF, Injector,
  Dyno, and Analysis workspaces.
- Added one searchable channel rail for parameters, switches, and external
  sensors, with a live selected-channel count.
- Added useful no-data screens to Data, Graph, Dashboard, MAF, Injector, and
  Dyno instead of leaving large blank panels.
- Added clear Graph controls for pause/resume, combined graphs, and reset.
- Moved Dashboard gauge style and min/max reset into the Dashboard where they
  belong.
- Added Ctrl+1 through Ctrl+7 shortcuts for fast workspace switching. The last
  selected workspace is still restored at startup.
- Cleaned up the Logger connection bar, recording controls, status display,
  table spacing, chart colours, and Light/Dark theme handling.
- Changed the missing-definition prompt to **Add definitions** and **Not now**.
  The Add action opens the real managed definition installer.
- Added parser tests around DM20 discovery data, runtime channels, and DimeMod
  diagnostic codes.

Editor

- A fresh install with no ROM definitions now offers **Add Definitions...** or
  **Not now** and opens Definition File Manager from the main action.
- Fixed map headers painting under Favorite and Search controls on Windows.
- Calibration tables now resize with the workspace while keeping horizontal
  scrolling when the window is genuinely narrow.
- Improved tab interaction, Favorites, recent/changed maps, ROM comparison,
  grouped undo/redo, notes, recovery, and integrated live data.

Definitions and files

- Logger definitions can be validated, installed, backed up, activated, and
  reloaded without using the old forum updater.
- Failed definition activation restores the previous file and settings.
- The Logger can close and reopen without an optional cars_def.xml file.
- Vehicle ROMs, definitions, profiles, and logs are not included in application
  or source packages.

Runtime and packages

- Linux and Windows use the same Java 21 source and regression suite.
- Both release ZIPs include a private runtime; a separate Java install is not
  needed.
- Windows checks both J2534 registry views and routes matching drivers directly
  or through the bundled x86/x64 bridge.
- Linux and Windows packages keep rolling diagnostics inside their own data
  location and never upload them automatically.
- Updated JNA, jSerialComm, and Log4j dependencies replace the old Java-era
  runtime pieces.

Known limits before RC3 can ship
--------------------------------

- The new Logger layout has passed automated tests and a Linux desktop visual
  check. A Windows visual pass is still required.
- Windows OpenPort/J2534 needs connected clean-machine testing.
- Linux needs the connected USB-removal/reconnect test repeated against the
  final candidate.
- Mitsubishi MUT-II logging still needs a vehicle test.
- ECU flashing and normal-user ECU memory writing are not available in 1.1.0.

What has already passed
-----------------------

- Linux OpenPort 2.0 ECU identification and sustained Subaru SSM/ISO9141
  logging passed in car.
- The Java 21 unit suite passes with the Logger workspace and DimeMod parser
  coverage.
- Windows and Linux package workflows build from the same source revision and
  verify their bundled files and checksums.
