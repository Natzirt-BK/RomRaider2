RomRaider2 ECU Studio 1.1.0 RC4
================================

RC4 is published as a development prerelease for early desktop and portable
platform feedback. The remaining hardware checks are listed below.

Changes since RC3
-----------------

Logger

- Added the first replacement Logger workspace using Compose Desktop while
  keeping one ECU session and one selected-channel list.
- Added Overview, Data, Graph, and Dashboard views with responsive normal and
  narrow layouts.
- Added Light and Dark themes, clearer channel colours, live telemetry status,
  recording controls, search, and Ctrl+1 through Ctrl+4 navigation.
- Persisted the selected replacement view and theme.
- Connected the replacement views to the real session, recording, channel, and
  live-sample services.
- Added an explicit Reconnecting state with a capped 1/2/4/5-second retry
  schedule and clearer disconnected feedback.

Editor and live tuning

- Added a UI-neutral live-tuning plan with bounded changes, overlap checks,
  stale-value protection, identity checks, and readback verification.
- Added projection of real changed Editor table bytes into an offline plan.
- Added a read-only Tune inspector with selected/all-changed scope, byte ranges,
  before/after values, and visible safety gates.
- Covered 3D table row gaps and X/Y axis changes in the offline projection.
- Added preflight checks for Subaru, the engine ECU, DimeMod state, mapped
  definitions, runtime RAM Tune discovery, and an exact ECU identity match.
- Kept execution restricted to the mock ECU transport. Production ECU memory
  writing and flashing remain unavailable.
- Improved the DimeMod panel and Editor inspector so mapped support and runtime
  RAM Tune discovery are reported separately.

Runtime and packages

- Added the Compose Logger and its platform renderer to the self-contained
  Linux and Windows package checks.
- Added the required Compose and Skia license notices.
- Added early native macOS packaging for both Apple silicon and Intel, plus a
  SteamOS Desktop Mode bundle. These remain development previews. The Android
  foundation is available separately as an explicitly experimental test APK,
  not as a desktop RC4 package.
- Expanded the Android foundation with traditional RomRaider CSV review and a
  read-only OpenPort preparation path for USB permission, firmware, and vehicle
  voltage checks.
- Wired an Android foreground-only Subaru SSM K-Line logger from exact ECU
  identification through profile resolution, bounded address reads, converted
  live values, and CSV recording. It rejects transmission-only parameters,
  exposes no ECU writes, and remains labeled for RC5 connected qualification.
- Added exact ROM-size and internal-ID matching for RomRaider ECU definitions
  on Android, with searchable named numeric tables, scaled cell values, and
  bounded offline edits. Android does not correct checksums and clearly marks
  saved files as review copies that must not be flashed.
- Fixed packaged settings precedence so an unrelated `settings.xml` beside the
  launch directory cannot replace the package-owned configuration.
- Updated candidate labels, verification scripts, and workflow artifacts for
  RC4 while leaving RC3 as the latest public download.

Checks completed
----------------

- The shared Java 21 suite passes with the live-tuning and settings-precedence
  regression tests.
- Compose tests pass and the replacement workspace stages successfully.
- The Linux Java 21 application image builds and its packaged launcher starts
  under a clean virtual display.
- Overview, Data, Graph, Dashboard, Dark, and narrow layouts have passed the
  current Linux visual review.
- The Android shared core passes definition inheritance, exact-match,
  conversion, editing, and mismatch tests. The APK builds, passes lint, and has
  passed a Waydroid launch and layout smoke check.

Known limits
------------

- RC4 desktop packages are public development previews rather than a stable
  release.
- The replacement Logger does not yet cover every specialized legacy
  workspace.
- The Windows package and visual pass wait until the Windows VM is available.
- No new in-car qualification is planned until RC5.
- Mitsubishi Lancer Evolution MUT-II still needs vehicle qualification.
- ECU flashing and production ECU memory writing are not available.
