# 1.1.9 RC1 qualification

September 9, 2026. Release preparation; final packages have not yet been qualified.

The preceding local pass passed 137 Android unit tests, emulator workflow and
recording-lifecycle checks, desktop core tests and 308 desktop workspace tests
with two optional skips. These are source checks, not final-package results.

The release gate includes hosted platform builds, Android upgrade regression,
package checksums, embedded versions/source identity, Android signing identity
and Linux/SteamOS launch and shutdown. Results will be recorded here before
downloads are published.

Physical phone touch/haptic feel, document-provider save/reopen behavior,
adapter/background/reconnect sessions, Steam Deck and interactive Windows/macOS
acceptance remain incomplete. RC1 is not a stable-release sign-off.
